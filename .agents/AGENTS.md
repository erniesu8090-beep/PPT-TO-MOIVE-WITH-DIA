# 專案規則與指引 (Workspace Rules)

## 黑底字幕配色原則 (Subtitle Color Rules)

在影片字幕製作（特別是黑底或深色背景）時，必須遵守以下配色規範以確保最佳的可讀度與觀眾視覺舒適度：

### 1. 不推薦/禁止使用的顏色 (Disallowed / Unrecommended Colors)
- **深藍色 / 海軍藍 (Dark Blue)**：與黑底彩度與明度極為接近，對比度不足，無法清楚辨識。
- **純紅色 / 深紅色 (Pure / Dark Red)**：在黑底上容易產生光學色差現象（Chromatism），導致字體邊緣模糊發脹，引發眼睛疲勞。
- **深綠色 / 墨綠 / 深紫 (Dark Green / Dark Purple)**：明度過低，字體輪廓會在黑底中隱沒。
- **高飽和度螢光色 (Hyper-saturated Neon)**：如極亮螢光綠、螢光藍，會產生視覺光暈（Halo Effect）與強烈刺眼殘影。

### 2. 推薦採用的顏色 (Recommended Colors)
- **白色 / 米白 (#FFFFFF / #F0F0F0)**：對比度最高、最經典耐看。（若覺刺眼可略微降彩為 90% 灰白）
- **明黃色 / 鵝黃 (#FFFF00 / #FADB14)**：黑底上醒目度與對比度最佳，適合關鍵字或角色對話強調。
- **淺天藍 / 亮水藍 (#40A9FF / #00FFFF)**：明度足夠的高對比暖藍/水藍。
- **檸檬綠 / 淺綠 (#A0D911 / #52C41A)**：高明度綠色。

### 3. 字幕輔助樣式規範 (Text Styling Best Practices)
- **必須包含描邊/陰影/黑框**：建議採用 `outline` (黑色細描邊 + 陰影) 或 `box` (半透明黑底背景)，以確保字幕在不同影片畫面上均清晰可讀。
- **字體粗細適中**：黑底白字具有光線擴散效應，字體不宜過度粗重疊加，字間距應保持適中。

## 極簡影片生成核心原則 (Lean Pipeline Rules)

雙人 Podcast 與影片自動化製作必須堅守**「大道至簡」的 3 步高速流**，嚴禁過度設計（Over-engineering）或徒增瑣碎繁雜的中間步驟：

1. **第一步：分析音檔**（提煉段落時間軸、對齊字幕與視覺意象）。
2. **第二步：生成適當圖片**（為各段落直接生成純視覺、高審美的概念大圖，嚴禁在畫面上塞入小字卡或文字簡報）。
3. **第三步：合成＋字幕**（舞台畫格合成與高對比雙軌字幕壓制，一氣呵成輸出 MP4）。

**禁止行為**：嚴禁額外切分多餘的特殊幻燈片模版、繁瑣的排版中轉或文字小卡，保持管線最快、最順、最純粹的高速產出！
