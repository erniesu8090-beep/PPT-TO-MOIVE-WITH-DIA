# 🎬 黑底字幕配色與設計指南

本指南旨在提升「影片製作工坊」產出影片之字幕可讀度（Accessibility & Readability），避免視覺疲勞與光學干擾。

---

## ❌ 不推薦使用的顏色

| 顏色類型 | 代表色碼/範例 | 不推薦原因 |
| :--- | :--- | :--- |
| **深藍色 / 海軍藍** | `#000080`, `#00008B` | 與黑底對比度極低，眼睛極難辨識字體輪廓 |
| **純紅 / 深紅色** | `#FF0000`, `#8B0000` | 人眼焦距效應（色差）導致字體發脹模糊，長時間極易疲勞 |
| **深綠 / 墨綠 / 深紫** | `#006400`, `#4B0082` | 明度過低，直接沉沒在黑色背景中 |
| **高飽和螢光色** | `#00FF00` (極亮螢光), `#FF00FF` | 產生強烈殘影與刺眼光暈 (Halo Effect) |

---

## 🟢 推薦使用的顏色

| 顏色類型 | 建議色碼 | 適用情境 |
| :--- | :--- | :--- |
| **白色 / 米白** | `#FFFFFF` / `#F0F0F0` | **主要字幕**（預設首選，對比度與清晰度最高） |
| **明黃色 / 鵝黃** | `#FFFF00` / `#FADB14` | **重點強調** / **角色 A 對話**（醒目度極佳） |
| **淺天藍 / 亮藍** | `#40A9FF` / `#00FFFF` | **次要強調** / **角色 B 對話** |
| **檸檬綠 / 淺綠** | `#A0D911` / `#52C41A` | **旁白 / 補充資訊** |
| **淺灰色** | `#CCCCCC` | **非重點說明字幕** |

---

## 💡 字幕設計 3 大關鍵技巧

1. **描邊與陰影 (Outline & Shadow)**
   - 始終保持字幕邊緣有黑色描邊或下層陰影，防範影片畫面中出現高亮背景時文字隱沒。
2. **避免字體過粗造成膨脹**
   - 黑底亮字會產生「光線擴散（Irradiation Effect）」，字體請選擇中等粗細（Medium/Bold），避免超重黑體。
3. **區分主次色調**
   - 全片建議不超過 2~3 種字幕顏色，主口白用白/黃，雙人對話可用天藍與黃色做區隔。
