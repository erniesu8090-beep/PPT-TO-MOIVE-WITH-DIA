# 雙人對話旁白腳本自動匯入與格式規範指南

本指南說明在使用「影片製作工坊」進行雙人對話式簡報影片製作時，口白腳本的撰寫規範與最佳實踐，以確保系統能 100% 順暢自動匯入、解析角色對白與精確合成配音。

---

## 1. 角色發言標籤 (Speaker Tags) 規範

系統支援多種靈活的角色標示格式，冒號使用半形 `:` 或全形 `：` 皆可自動識別：

### 🔷 角色 A (主講人 / Host)
* `A:` 或 `A：` *(最推薦)*
* `[A]`
* `主持人:`、`Host:`
* `甲:`、`角色A:`、`角色1:`

### 💜 角色 B (對談者 / Guest)
* `B:` 或 `B：` *(最推薦)*
* `[B]`
* `專家:`、`來賓:`、`Guest:`
* `乙:`、`角色B:`、`角色2:`

---

## 2. 腳本撰寫格式範例

### 格式 A：單行連續書寫（適合簡潔輸入）
```text
A: 各位好，歡迎來到今天的理財對談節目。 B: 沒錯！今天我們要深入探討如何進行合理的資產配置。
```

### 格式 B：換行分段書寫（最推薦，清晰易讀）
```text
A: 各位好，歡迎來到今天的理財對談節目。
B: 沒錯！今天我們要深入探討如何進行合理的資產配置。
A: 這裡展示了著名的收入物理學法則，專家你有什麼看法？
B: 我認為持續投資自己，才是回報率最高的商業模式。
```

---

## 3. 標點符號與字幕切分注意事項

1. **標點符號規範**：
   - 句子之間請使用標準標點符號（如逗號 `，`、句號 `。`、問號 `？`、感嘆號 `！` 或分號 `；`）。
   - 系統依據標點符號自動切分字幕子句，並計算動態字幕呈現時間碼與語音對齊。

2. **內文符號避坑**：
   - 句中內文請避免單獨出現獨立的 `A:` 或 `B:` 字樣，以免被解析器誤判為角色切換。

3. **網頁 GUI 快速插入**：
   - 網頁介面口白編輯器中，可直接點擊 **`+ A (主持人)`** 或 **`+ B (對談者)`** 按鈕，即可在游標位置一鍵插入標準對話標籤。
