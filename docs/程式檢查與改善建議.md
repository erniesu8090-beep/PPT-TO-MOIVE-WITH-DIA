# 程式檢查與改善紀錄

更新日期：2026-10-14。

## 已完成的五項優先改善

| 項目 | 現在的行為 |
| --- | --- |
| 音檔時長 | `core/media_utils.py` 驗證音檔與 ffprobe 回傳值，讀取失敗、缺少工具、逾時或無效時長會明確報錯，不再當成 5 秒。尚未生成配音時，編輯用時序會標示 `estimated`；影片合成拒絕使用這種估算 |
| 字幕長句 | `core/subtitle_utils.py` 共用標點切句、無標點長文切分、每行最多 18 字、最多兩行、每筆最多 5 秒、發言者標籤只出現在該段首句。簡報與 Podcast 都已接入；時間碼四捨五入會正確進位 |
| 無口白頁 | 批次生成不再跳過空白頁，而是產生靜音。可在語音設定選擇 1～120 秒，預設 5 秒。時間軸忽略舊口白／字幕，影片合成也強制使用靜音來源。整份專案都是靜音頁時也可輸出 |
| 作業鎖 | 同一個伺服器的渲染、試聽、匯入、口白與設定儲存共用一把鎖；第二個寫入操作會回報忙碌，避免多視窗互相覆寫。字幕文字預覽可繼續使用，忙碌時不讀取正在替換的配音檔。渲染連線中斷後仍完成作業並保留鎖至結束 |
| 配音快取 | 依口白、有效聲音／語速／音高及 TTS 版本逐頁快取，另以音檔雜湊偵測損毀。改字幕顏色、字體、角色名稱或停頓不需重製語音。提供「重新生成全部配音（忽略快取）」選項。先在暫存目錄完成配音與驗證，再替換正式檔，失敗頁不會覆蓋原本的有效音檔 |

第一次使用新版時，舊音檔因沒有快取指紋，會重製一次。之後未改動的頁面可直接沿用。

## 介面與字幕預覽

- 預設改成暖灰／深綠暗色介面，降低大面積白底及裝飾橫幅亮度。
- 字幕預覽使用目前投影片和本頁口白，主預覽區可開關字幕，側欄與放大視窗可切換句子。
- 字體大小與底部距離以 1920 × 1080 座標等比例顯示。時間尚未生成時明確標示估算，生成後使用配音時間碼。
- 「檢視 FFmpeg 實際輸出」會以目前尚未儲存的設定渲染一張 PNG，ASS 樣式與最終影片共用 `core/subtitle_styles.py`。可確認真正的字型、描邊、色彩與換行；不含頁碼／角色卡等舞台裝飾。
- 切換句子或修改設定後會清除舊實際畫格，避免誤認為已套用新的設定。
- 保留手機版面、鍵盤選頁、空白專案提示、字數與頁數資訊。

## 同時修正的問題

- 原本雙人對話解析在辨識 A／B 標籤後缺少擷取文字與回傳結果，已補齊並加入測試。
- 載入雙人範例只填入本頁編輯框，不再直接覆寫整份專案。
- 編譯／渲染／字幕失敗會終止前端等待；後端檢查回報的輸出檔案是否存在。
- 字幕文字以文字節點顯示；ASS 控制符號會轉成可見文字，避免被當成排版命令。

## 尚可繼續改善

1. **匯入失敗復原**：新簡報先完整產生到暫存專案，驗證完成後才替換目前專案，保留前一版。
2. **錯誤日誌**：保留 FFmpeg 完整 stderr 日誌，介面顯示摘要與日誌位置。
3. **多專案**：目前仍使用一組專案 JSON；可改成 `projects/<id>/`，加入最近作品與歷史版本。
4. **前端分離**：CSS 和字幕預覽 JavaScript 已獨立，主要 HTML 與其他 JavaScript 仍可再拆檔；不必因此改用大型框架。
5. **依賴整理**：Node.js 與 Python Playwright 目前分別供兩條管線使用，不能直接刪掉其中一個。可以在後續統一為 Python Playwright。

## faster-whisper 的用途

`faster-whisper` 是以 Whisper 模型進行語音辨識的工具，可把錄音、Podcast 或影片音軌轉成文字及時間碼；方向與 edge-tts 的文字轉語音相反。目前專案仍未呼叫它，依賴保留。日後可接入「匯入音檔 → 轉錄 → 校對 → 字幕」；既有 edge-tts 合成流程已能取得時間資訊，不需再用 Whisper 辨識一次。參考：[官方專案](https://github.com/SYSTRAN/faster-whisper)。

根目錄 `assets/` 的疑似舊素材約 35.5 MB 仍保留，本次未刪除。
